# Поличка

Приватний застосунок-поличка для фільмів, серіалів, книг і музичних альбомів.
Чистий HTML/CSS/JS, без збірки та залежностей. Дані зберігаються у localStorage браузера.

## Запуск локально

Просто відкрий `index.html` у браузері — або постав будь-який статичний сервер, напр.:

```
npx serve .
```

## Деплой

Задеплой на GitHub Pages або Netlify (безкоштовно) — інструкція в чаті з Claude, де це створювалось.
